# লুক্সোরা হিসাব নিকাশ (Luxora Hisab Nikash)

বাংলা ভাষার সহজ হিসাব-নিকাশের অ্যান্ড্রয়েড অ্যাপ। Kotlin + Jetpack Compose + Room। ইন্টারনেট ছাড়া চলে, কোনো সাবস্ক্রিপশন নেই।

## ⚠️ গুরুত্বপূর্ণ
এই সোর্স কোড আমি লিখেছি, কিন্তু আমার পরিবেশে অ্যান্ড্রয়েড SDK/ইন্টারনেট না থাকায় **APK কম্পাইল করে টেস্ট করা হয়নি**। তৈরি APK এখানে দেওয়া সম্ভব হয়নি। নিচের ধাপে আপনি নিজে APK বানাবেন। প্রথম বিল্ডে ছোটখাটো কম্পাইল ত্রুটি আসতে পারে — এরর মেসেজ পাঠালে ঠিক করে দেব।

## APK বানানোর পদ্ধতি ১: Android Studio (কম্পিউটারে)
1. https://developer.android.com/studio থেকে Android Studio (ফ্রি) ইনস্টল করুন।
2. এই ZIP আনজিপ করুন → Android Studio তে **Open** → `LuxoraHisabNikash` ফোল্ডার নির্বাচন করুন।
3. "Gradle Sync" শেষ হওয়া পর্যন্ত অপেক্ষা করুন (প্রথমবার ইন্টারনেট লাগবে, SDK 34 ডাউনলোড হবে)।
4. মেনু: **Build → Build Bundle(s) / APK(s) → Build APK(s)**।
5. শেষ হলে "locate" চাপুন। ফাইল: `app/build/outputs/apk/debug/app-debug.apk`।
   (ফোনে ইনস্টলের জন্য এটিই যথেষ্ট। চাইলে Build → Generate Signed Bundle/APK দিয়ে নিজের কী-স্টোরে সাইন করতে পারেন।)

## পদ্ধতি ২: কম্পিউটার ছাড়া (GitHub Actions, ফ্রি)
1. github.com এ ফ্রি অ্যাকাউন্ট খুলে নতুন repository বানান।
2. এই ফোল্ডারের সব ফাইল (`.github` ফোল্ডারসহ) আপলোড করুন।
3. **Actions** ট্যাব → "Build APK" → **Run workflow**।
4. ৫–১০ মিনিট পরে রান-এর পাতা থেকে `LuxoraHisabNikash-apk` ডাউনলোড করুন (ZIP-এর ভেতরে app-debug.apk)।

## ফোনে ইনস্টল
1. APK ফাইলটি ফোনে নিন (USB, WhatsApp, ব্লুটুথ বা Google Drive দিয়ে)।
2. ফাইলে চাপ দিন। "অজানা উৎস থেকে ইনস্টল" জিজ্ঞেস করলে **Settings → অনুমতি দিন**।
3. **Install** চাপুন। (Android 8.0 বা তার উপরের ফোন লাগবে।)
4. পরে অন্যদের দিতে: অ্যাপের **আরও → ব্যাকআপ, রিস্টোর, সিঙ্ক ও APK শেয়ার → এই অ্যাপের APK শেয়ার করুন**।

## হিসাবের নিয়ম
- **ব্যালেন্স** = নগদ পাওয়া আয় − নগদ দেওয়া ব্যয়।
- **পাওনা** = আয়ের এন্ট্রিতে (মোট − নগদ পাওয়া)। **দেনা** = ব্যয়ের এন্ট্রিতে (মোট − নগদ দেওয়া)।
- বাকি থাকলে ব্যক্তির নাম বাধ্যতামূলক।
- সপ্তাহ শনিবার থেকে শুরু।

## মাল্টি-ফোন সিঙ্ক — সীমাবদ্ধতা
- সিঙ্ক **ফাইল-ভিত্তিক**: এক ফোন থেকে "সিঙ্ক ফাইল পাঠান", অন্য ফোনে "সিঙ্ক ফাইল মেলান"। দুই দিকেই করলে দুই ফোনের ডেটা এক হয়।
- প্রতিটি রেকর্ডের UUID আইডি থাকায় ডুপ্লিকেট হয় না; একই রেকর্ড দুই ফোনে বদলালে সর্বশেষ সময়েরটি থাকে। মুছে ফেলাও সিঙ্ক হয়।
- স্বয়ংক্রিয় রিয়েল-টাইম সিঙ্ক (সার্ভার/ওয়াই-ফাই) এই সংস্করণে নেই; তার জন্য সার্ভার বা লোকাল নেটওয়ার্ক কোড যোগ করতে হবে।

## PDF সম্পর্কে
Android-এর নিজস্ব PdfDocument ও সিস্টেম বাংলা ফন্ট ব্যবহার হয় (বাইরের লাইব্রেরি/ফি নেই)। প্রথম টেস্টে যুক্তাক্ষর ঠিক দেখাচ্ছে কিনা অবশ্যই দেখে নিন।
